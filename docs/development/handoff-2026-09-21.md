## 実装済み内容

### 品質ゲート

- `biome.json`でTypeScript/TSX/JavaScript/JSONのformatterとrecommended lint presetを有効化した。
- `pnpm run format`、`pnpm run format:check`、`pnpm run lint`、`pnpm run check:gofmt`、`pnpm run check`を追加した。
- `scripts/check-gofmt.mjs`はtracked Go fileだけを非破壊で検査し、`scripts/check-gofmt.test.mjs`で検証する。

### Runtime configuration

`internal/config/config.go`の`config.Load(lookup)`は、DB/OIDC設定、TTL、32-byteのbase64 auth transaction key、cookie securityを検証する。`APP_COOKIE_SECURE=false`は、`development`かつlisten addressとallowed originがloopbackの場合だけ許可する。

直接Go dependencyは以下に固定されている。

- `github.com/coreos/go-oidc/v3` 3.21.0
- `golang.org/x/oauth2` 0.37.0
- `github.com/golang-migrate/migrate/v4` 4.20.1
- `github.com/jackc/pgx/v5` 5.11.0

### PostgreSQL migrationとテスト環境

- `migrations/000001_initial_workflow.*.sql`: Organization、Member、role、Request、Approval、Audit Event。
- `migrations/000002_auth_sessions.*.sql`: server-side sessionとOIDC auth transaction。
- `compose.test.yaml`: loopbackの`127.0.0.1:55432`だけへ公開するテスト専用PostgreSQL 17.11。
- `pnpm run test:db`: Compose起動、health check、`TEST_DATABASE_URL`注入、migration up/down test、container/network/volume破棄を一連で実施する。

## 既知の判断・注意事項

- Go 1.27では、将来利用するGo moduleがまだimportされていない中間段階で通常の`go test ./...`がmodule graph更新を要求する。Task 1/2では`-mod=mod`を明示し、`go.mod`/`go.sum`の差分をレビューした。全packageが実装されたTask 8で通常の全suiteを再評価する。
- `pnpm test`はVitest test fileが未作成のため、現時点では`No test files found`で失敗する。Task 0のNode testは`node --test scripts/check-gofmt.test.mjs`で実行する。Task 8までにVitest component testが追加される予定である。
- `compose.test.yaml`のPostgreSQL imageは`postgres:17.11-bookworm`に固定しているがdigest固定ではない。開発テスト環境向けであり、image更新・digest固定が必要になった場合は依存更新としてレビューする。
- 実行記録とrulingは`.superpowers/sdd/2026-09-20-go-api-implementation/progress.md`に日本語で保存している。このdirectoryはgit管理対象外である。
